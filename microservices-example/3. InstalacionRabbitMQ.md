# Instalación de RabbitMQ y creación del tópico — Sales Microservices

Esta guía cubre la instalación de RabbitMQ en local y la creación del
exchange, las colas y los bindings definidos en la arquitectura del
proyecto (ver `arquitectura-sales-microservices.md`).

## 1. Instalación

### Opción A — Homebrew (macOS)

```bash
brew update
brew install rabbitmq
brew services start rabbitmq
```

### Opción B — Docker

```bash
docker run -d --name rabbitmq \
  -p 5672:5672 -p 15672:15672 \
  rabbitmq:3-management
```

En ambos casos la consola de administración queda disponible en:

```
http://localhost:15672
```

Usuario / contraseña por defecto: `guest` / `guest` (solo válido desde
`localhost`).

## 2. Crear el exchange

En la consola de administración → pestaña **Exchanges** → *Add a new
exchange*:

| Campo | Valor |
|---|---|
| Name | `sales.topic` |
| Type | `topic` |
| Durability | Durable |

## 3. Crear las colas

En la pestaña **Queues** → *Add a new queue*, crear:

| Nombre de la cola | Durability |
|---|---|
| `billing.sale-created.queue` | Durable |
| `inventory.sale-created.queue` | Durable |

## 4. Enlazar las colas al exchange (bindings)

Entrar a cada cola → sección **Bindings** → *From exchange*:
`sales.topic`.

| Cola | Routing key |
|---|---|
| `billing.sale-created.queue` | `sale.created` |
| `inventory.sale-created.queue` | `sale.created` |

Con esto, cualquier mensaje publicado en `sales.topic` con routing key
`sale.created` llega a **ambas** colas — cada microservicio consume su
propia copia.

## 5. Prueba manual

En **Exchanges** → `sales.topic` → sección **Publish message**:

- Routing key: `sale.created`
- Payload: el JSON de ejemplo del `SaleCreatedEvent` (ver
  `arquitectura-sales-microservices.md`, sección 3)

Publicar y verificar que el contador de mensajes sube tanto en
`billing.sale-created.queue` como en `inventory.sale-created.queue`.

## 6. Datos de conexión para los microservicios

Estos son los valores que `sales-microservices` (publicador) y
`billing-microservices` / `inventory-microservice` (consumidores)
usarán en su configuración (por ejemplo `application.yml` en Spring
Boot):

```yaml
spring:
  rabbitmq:
    host: localhost
    port: 5672
    username: guest
    password: guest
```

| Servicio | Rol | Exchange | Routing key | Cola |
|---|---|---|---|---|
| `sales-microservices` | Publica | `sales.topic` | `sale.created` | — |
| `billing-microservices` | Consume | `sales.topic` | `sale.created` | `billing.sale-created.queue` |
| `inventory-microservice` | Consume | `sales.topic` | `sale.created` | `inventory.sale-created.queue` |
