# Guía de ejecución — Microservicios

## Prerequisitos

- Java 21
- Maven (o usar el wrapper `./mvnw`)
- PostgreSQL corriendo en `localhost:5432`
- RabbitMQ corriendo en `localhost:5672`

Crear las bases de datos antes de arrancar:

```sql
CREATE DATABASE sales_db;
CREATE DATABASE billing_db;
CREATE DATABASE inventory_db;
```

---

## 1. sales-microservice — Puerto 8080

### Configurar variables de entorno

```bash
cp sales-microservice/.env.example sales-microservice/.env
```

Contenido del `.env`:

```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=sales_db
DB_USERNAME=postgres
DB_PASSWORD=admin
```

### Correr

```bash
cd sales-microservice
./mvnw spring-boot:run
```

### Verificar

- Swagger UI: http://localhost:8080/swagger-ui.html
- API Docs:   http://localhost:8080/api-docs

## Orden de arranque recomendado

1. PostgreSQL
2. RabbitMQ
3. `sales-microservice`
4. `billing-microservices` y `inventory-microservice` (en cualquier orden)

`billing` e `inventory` son consumidores independientes — si uno está caído, el otro igual procesa su cola.

---

## Prueba end-to-end

### 1. Ver productos disponibles

```bash
curl http://localhost:8080/api/products
```

### 2. Registrar una venta

```bash
curl -X POST http://localhost:8080/api/sales \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      { "productId": 1, "quantity": 2 },
      { "productId": 3, "quantity": 1 }
    ]
  }'
```

### 3. Verificar la factura generada (billing)

```bash
curl http://localhost:8081/api/invoices
```

### 4. Verificar el descuento de stock (inventory)

```bash
curl http://localhost:8082/api/stock
```
